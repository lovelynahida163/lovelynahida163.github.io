TransONet 是一个纯 Transformer 的算子学习模型。它的核心思想是：**把输入函数的采样点和输出查询点统一成一个序列，然后用自注意力建模所有点对之间的依赖**。

核心公式：

`X = [u(x1), u(x2), ..., u(xm), y1, y2, ..., yq]`

`Z = SelfAttention( XW_Q, XW_K, XW_V )`

`output = MLP( Z[m+1 : m+q] )`  ，只取查询点对应的输出

具体过程：

1. 将输入函数的采样值 `u(x_i)` 和输出查询点的坐标 `y_j` 拼接到一起，形成一个长度为 `m+q` 的序列。每个元素还可以加上位置编码。
2. 把这个序列送入标准的 Transformer 编码器（自注意力 + 前馈网络）。
3. 自注意力机制让每个位置都能看到所有其他位置，因此输入函数的信息可以自由流向查询点。
4. 最后取出查询点对应的那些位置的特征，通过 MLP 得到 `G(u)(y_j)`。

TransONet 的结构非常干净：没有分支‑主干的双网络，没有频域变换，只有一个 Transformer。它的表达能力很强，可以处理时序 PDE、时空耦合问题，因为自注意力天然支持长序列的时间依赖。

适用场景：时间相关的 PDE（比如对流‑扩散、波动方程）、长序列预测、时空数据建模。

缺点：纯自注意力的复杂度是 `O((m+q)^2)`，当输入采样点和输出查询点都很多时非常昂贵。通常需要对序列做截断或使用稀疏注意力。另外它需要更多的数据来训练，因为 Transformer 参数量大、容易过拟合。

TransONet 是纯 Transformer 结构，将输入函数采样点和输出查询点放在**同一个序列**中，用自注意力让它们互相看见。

**输入**：
- 传感器点：`{(x_i, u(x_i))}`，`i=1..m`。
- 查询点：`{y_j}`，`j=1..q`。

**第一步：构造序列**  
每个传感器点编码为：`e_i = MLP_enc( [x_i; u(x_i)] )`。  
每个查询点编码为：`f_j = MLP_enc_y( y_j )`。  
将它们拼接成一个长序列：`S = [e_1, e_2, ..., e_m, f_1, f_2, ..., f_q]`，长度 `m+q`，每个元素维度 `d_model`。加上位置编码（例如正弦编码或可学习的）。

**第二步：自注意力块（多个层）**  
标准 Transformer 编码器层：
- 多头自注意力：`S' = S + MultiHeadAttn( S, S, S )`（加残差）。
- 层归一化。
- 前馈网络：`S'' = S' + FFN( S' )`。
- 层归一化。

经过 L 层后，序列中的每个位置都已经融合了所有其他位置的信息。

**第三步：提取输出**  
取出序列中对应查询点的部分（后 q 个位置）：`h_j = S''[m+j]`。  
通过 MLP 输出：`G(u)(y_j) = MLP_out( h_j )`。

**特点**：没有分支‑主干分离，也没有显式的积分核。所有信息交换靠自注意力完成。适合时序问题，因为可以把不同时间步的输入和查询放在一个序列里。

一句话：**时序 PDE、长程时间依赖，TransONet 值得一试**。

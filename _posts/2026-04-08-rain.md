## 一、传世名篇
### 魏晋南北朝
| 简体版 | 繁體版 |
| :--- | :--- |
| 《苦雨》（节选）<br>南朝宋·鲍照<br><br>连阴积浇灌，滂沱下霖乱。<br>沉云日夕昏，骤雨望朝旦。<br>洪流泻天渊，激浪灌河汉。 | 《苦雨》（節選）<br>南朝宋·鮑照<br><br>連陰積澆灌，滂沱下霖亂。<br>沉雲日夕昏，驟雨望朝旦。<br>洪流瀉天淵，激浪灌河漢。 |

### 唐

| 《登柳州城楼寄漳汀封连四州刺史》<br>唐·柳宗元<br><br>城上高楼接大荒，海天愁思正茫茫。<br>惊风乱飐芙蓉水，密雨斜侵薜荔墙。<br>岭树重遮千里目，江流曲似九回肠。<br>共来百越文身地，犹自音书滞一乡。 | 《登柳州城樓寄漳汀封連四州刺史》<br>唐·柳宗元<br><br>城上高樓接大荒，海天愁思正茫茫。<br>驚風亂颭芙蓉水，密雨斜侵薜荔牆。<br>嶺樹重遮千里目，江流曲似九回腸。<br>共來百越文身地，猶自音書滯一鄉。 |
| 《咸阳城东楼》<br>唐·许浑<br><br>一上高城万里愁，蒹葭杨柳似汀洲。<br>溪云初起日沉阁，山雨欲来风满楼。<br>鸟下绿芜秦苑夕，蝉鸣黄叶汉宫秋。<br>行人莫问当年事，故国东来渭水流。 | 《咸陽城東樓》<br>唐·許渾<br><br>一上高城萬里愁，蒹葭楊柳似汀洲。<br>溪雲初起日沉閣，山雨欲來風滿樓。<br>鳥下綠蕪秦苑夕，蟬鳴黃葉漢宮秋。<br>行人莫問當年事，故國東來渭水流。 |
| 《秋雨叹三首·其一》<br>唐·杜甫<br><br>阑风长雨秋纷纷，四海八荒同一云。<br>去马来牛不复辨，浊泾清渭何当分？<br>禾头生耳黍穗黑，农夫田妇无消息。<br>城中斗米换衾裯，相许宁论两相值？ | 《秋雨歎三首·其一》<br>唐·杜甫<br><br>闌風長雨秋紛紛，四海八荒同一雲。<br>去馬來牛不復辨，濁涇清渭何當分？<br>禾頭生耳黍穗黑，農夫田婦無消息。<br>城中斗米換衾裯，相許寧論兩相值？ |
| 《大水》（节选）<br>唐·白居易<br><br>浔阳郊郭间，大水岁一至。<br>闾阎半飘荡，城堞多倾坠。<br>苍茫生海色，渺漫连空翠。<br>风卷白波翻，日煎红浪沸。<br>工商彻屋去，牛马登山避。 | 《大水》（節選）<br>唐·白居易<br><br>潯陽郊郭間，大水歲一至。<br>閭閻半飄蕩，城堞多傾墜。<br>蒼茫生海色，渺漫連空翠。<br>風卷白波翻，日煎紅浪沸。<br>工商徹屋去，牛馬登山避。 |
| 《横江词六首·其五》<br>唐·李白<br><br>横江馆前津吏迎，向余东指海云生。<br>郎今欲渡缘何事？如此风波不可行！ | 《橫江詞六首·其五》<br>唐·李白<br><br>橫江館前津吏迎，向余東指海雲生。<br>郎今欲渡緣何事？如此風波不可行！ |

## 二、冷门佳作
### 宋
| 简体版 | 繁體版 |
| :--- | :--- |
| 《观雨》<br>宋·陈与义<br><br>山客龙钟不解耕，开轩危坐看阴晴。<br>前江后岭通云气，万壑千林送雨声。<br>海压竹枝低复举，风吹山角晦还明。<br>不嫌屋漏无干处，正要群龙洗甲兵。 | 《觀雨》<br>宋·陳與義<br><br>山客龍鍾不解耕，開軒危坐看陰晴。<br>前江後嶺通雲氣，萬壑千林送雨聲。<br>海壓竹枝低復舉，風吹山角晦還明。<br>不嫌屋漏無乾處，正要群龍洗甲兵。 |
| 《大暑舟行含山道中，雨骤至，霆奔龙挂可骇》（节选）<br>宋·范成大<br><br>隤云暧前驱，连鼓讧后殿。<br>白龙起幽壑，竹尾卷急电。<br>倾河决层霄，万瓦沸飞霰。 | 《大暑舟行含山道中，雨驟至，霆奔龍掛可駭》（節選）<br>宋·范成大<br><br>隤雲曖前驅，連鼓訌後殿。<br>白龍起幽壑，竹尾卷急電。<br>傾河決層霄，萬瓦沸飛霰。 |
| 《雨作抵暮复晴五首·其一》<br>宋·杨万里<br><br>惊雷势欲拔三山，急雨声如倒百川。<br>谁作春晴三日好，又吹雨暗暮江天。 | 《雨作抵暮復晴五首·其一》<br>宋·楊萬里<br><br>驚雷勢欲拔三山，急雨聲如倒百川。<br>誰作春晴三日好，又吹雨暗暮江天。 |
| 《次韵文潜》（节选）<br>宋·黄庭坚<br><br>武昌赤壁吊周郎，寒溪西山寻漫浪。<br>忽闻天上蛟龙怒，倒泻银河入篷舫。 | 《次韻文潛》（節選）<br>宋·黃庭堅<br><br>武昌赤壁吊周郎，寒溪西山尋漫浪。<br>忽聞天上蛟龍怒，倒瀉銀河入篷舫。 |
